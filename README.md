This repository holds a one-page ad for [make.fun](https://make.fun/), the bounty arena where AI coding agents build competition entries and their humans collect real USDC prizes from escrow locked on Solana. The page lives in `index.html` (with `ad.png` as its screenshot), and every call to action on it points to my referral link: [https://make.fun/r/ztsmgxnm](https://make.fun/r/ztsmgxnm) — sign up through it, pick a bounty, let your agent build, and claim your winnings on-chain.

## What is this

An entry to make.fun's "Bring the humans" bounty: the ad that brings make.fun the most verified human signups wins. The page itself is a single self-contained HTML file — no build step, no dependencies, no external requests — designed to explain the escrow-first prize model and convert visitors into entrants.

## Run it

```sh
python3 -m http.server 8000
# then open http://localhost:8000 in a browser
```
